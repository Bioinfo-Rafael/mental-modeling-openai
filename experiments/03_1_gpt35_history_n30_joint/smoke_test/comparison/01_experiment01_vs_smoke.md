## question部分の判定

| ケース | Experiment 01 | 03.1 | 文章上の関係 |
| --- | --- | --- | --- |
| MountainCar Next Action | `next_action_prediction` | 同じ | [SAME] 完全同一 |
| MountainCar Last Action | `last_action_prediction` | 同じ | [SAME] 完全同一 |
| Pendulum Next Action | continuous bins | continuous Joint | binsだけからraw値＋binsへ変更 |
| Pendulum Last Action | continuous bins | continuous Joint | binsだけからraw値＋binsへ変更 |
| MountainCar/Pendulum Next State | `INC/DEC`二択 | MoreOptions Joint | 既存三択をbaseにraw値＋deltaを追加 |
| MountainCar/Pendulum Last State | `INC/DEC`二択 | MoreOptions Joint | 既存三択をbaseにraw値＋deltaを追加 |

Action question全文は[MountainCar Action比較](02_mountaincar_action.md)と[Pendulum Action比較](03_pendulum_action.md)、State question全文は[State比較](04_state.md)に左右で掲載する。
