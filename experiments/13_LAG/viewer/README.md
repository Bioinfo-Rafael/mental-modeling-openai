# LAG Match Inspector

3試合の録画・機体の状態と行動・行動確率を、同じstepで閲覧するローカルHTMLツール。左に録画、右に時系列／確率分布を配置し、数値一覧は表示しない。

## 起動

リポジトリルートから、既存のPython環境で実行する（pandas、ffmpeg、ffprobeが必要）。

```sh
.venv/bin/python experiments/13_LAG/viewer/serve.py
```

ブラウザで <http://127.0.0.1:8130/viewer/> が開く。終了はターミナルでCtrl+C。
ポート変更は `--port 8131`、自動でブラウザを開かない場合は `--no-open`。
HTMLファイルの直接オープンではなく、このサーバーを使う。初回起動時に録画からJPEGフレームを生成する。以後は録画のハッシュが同じなら再利用する。ブラウザの動画デコーダーに依存せず、指定フレームを表示する。

`21_foresight_LAG2/results/sliding_n1_v1/report/` から起動時に読み込む。
対象試合は `mhi_v1.3_ic100601_win`。他の試合には結果なしと表示する。
結果ファイルの更新後はサーバーを再起動してページを再読み込みする。

実験20は注釈step 46・49・83・95・143・243で切り替える。
表示区間は0–48がstep 46の回答、49–82がstep 49の回答、83–94がstep 83の回答となる。
最後の回答は試合終端まで保持する。実験21は入力窓末尾のstep 30・45・60…330で切り替える。

最初の回答をstep 0から表示するのは閲覧用の規則。実際のAPI到着時刻の再現ではない。
入力範囲と予測対象範囲をカードに併記し、API遅延による表示時刻の変更は行わない。
シーク・巻き戻しでも同じ区間の回答を表示する。

## 操作

- 試合と4機の機体を選択。機体・グラフタブを切り替えてもstepを維持する。
- Spaceで再生・停止、左右キーで1step、Shift＋左右キーで1秒移動。数値入力中は入力を優先。
- スライダー、step・秒入力、グラフのクリックでも移動可能。
- 速度はシミュレーション時間を基準に0.25 / 0.5 / 1 / 2 / 4倍。
- 前／次の発射と発射一覧は選択機体の発射結果stepに移動する。
- 「確率分布」は現在stepの4分布・13確率を表示。選択行動を強調。
- 「状態・行動の時系列」は全状態・4行動・2計算値から表示項目を選択。グラフ上にポインターを置くと最寄りstepの値を表示する。

## 時間・データの意味

整数stepを時間の基準とし、`time_s = step × 0.2`。状態はその時刻、行動は `[t, t+0.2秒)` に適用される。
録画は10fps・4倍速で、風景の記録間隔は0.4秒。元動画の各フレームをそのままの解像度でJPEGに変換し、対応フレームを表示する。時間の補間はしない。奇数stepでは直前の風景が表示され、終端は最後の映像フレームに留まる。映像時刻とシミュレーション時刻を分けて表示し、画像読み込み中は「同期中」と示す。

発射要求 `shoot_action`、発射結果 `missile_launched`、ACMIでのミサイル初出は別の情報。今回の17発は発射結果の行の1step後にACMI初出がある。グラフでは橙が発射結果の行動step、紫がACMI初出。ミサイルの消滅から命中は推定しない。

欠損値は0・hold・一様確率で補完しない。B側の行動・確率、撃墜後の行動等は未収録と表示する。終端で機体レコード自体がない場合は「このstepの記録なし」。発射結果の空欄は、そのCSV行に発射記録がないことを意味する。

機首方位の変化率と水平進行方向の変化率は、連続する生存中の2stepから角度差を−180〜180°に折り返して計算する。後者は速度の北・東成分から算出し、水平速度がほぼ0の場合は未定義とする。値は直前区間の平均であり、瞬間角速度ではない。元の角度グラフは記録値をそのまま表示するため、0/360°境界で線が跳ぶ場合がある。

## 実装とデータ

- `prepare.py`: 既存 `lag_data.dataset.load_episode` でハッシュ・スキーマ・キーを検証後、CSVの文字列表現を保持した閲覧JSONと、録画のJPEGフレームを生成。
- `data/viz/viewer/`: 再生成可能なJSONとフレーム画像。Git管理対象外。原本は変更しない。
- `serve.py`: localhost限定の静的HTTPサーバー。実験13のディレクトリを配信。
- `app.js`: 機体選択・表示タブ。
- `playback.js`: step時計と録画フレームの表示。
- `charts.js`: SVG時系列と確率バー。外部ライブラリ・CDN不要。
- `model.js`: 項目定義と計算値・動画フレーム対応。

ビューアは実験20・21の保存済み回答を表示する。外部送信機能は持たない。
