# LAG 2v2 ACMI（学習モデルの対戦記録）

LAG の 2v2 で、学習したモデルが固定ルールの相手と戦った試合の記録（ACMI）と、その動画。こちらで学習したモデルが無傷で勝った試合と、別の初期配置でこちらのモデルが負けた試合・同じ初期配置で MHI 先方モデル（v1.3）が勝った試合の、計 3 試合。こちらのモデルは、決定論の評価（初期配置 20 通り）で 15 勝 3 敗 2 分。背景は [[sources/YutaSawada/20261005_MHI先方モデル再現と2v2同条件学習/20261005_MHI先方モデル再現と2v2同条件学習\|MHI 先方モデルの再現と 2v2 同条件学習]] を参照。

## 条件（3 本で共通）

| 項目 | 内容 |
|---|---|
| 形式 | 2v2。赤（A0100・A0200）が学習したモデル、青（B0100・B0200）が固定ルール（追跡：最も近い敵を追って、発射条件に入れば撃つ） |
| 初期配置 | seed 100600〜100619 のうち 100606 と 100601（100601 は両軍の初期距離が約 18.5〜19.5 km、高度約 6 km） |
| 発射条件 | 角度 45° 以内・距離 14 km 以内。各機ミサイル 2 発 |
| 行動の選び方 | 決定論（各時刻でいちばん確率の高い行動） |
| 時間刻み | 0.2 秒ごと（1 試合は最大 200 秒） |

## ACMI の見方

- Tacview（無料版で可）でそのまま開ける。動画でよければ `recordings/` の mp4 を見る。
- 各行は「時刻（`#秒`）→ 各オブジェクトの状態」。主な項目は次のとおり。

| 項目 | 意味 |
|---|---|
| `T=経度\|緯度\|高度\|ロール\|ピッチ\|ヨー` | 位置（度・m）と姿勢（度） |
| `Name` | 機体名（F16）、ミサイル名（AIM-9L） |
| `Color` | 陣営（Red / Blue） |
| `TAS` | 真対気速度（m/s） |
| `Health`・`Missiles` | 機体の状態と残弾数 |
| ミサイルの ID | 発射した機体の ID の後ろに番号（例 `A01002` は A0100 が撃ったミサイル） |
| `-ID` | そのオブジェクトの消滅（撃墜・ミサイルの終了） |
| `Type=Misc+Explosion,Name=SHOTDOWN` | 撃墜の表示 |

## 試合の流れ

### こちらのモデルの勝ち（初期配置 100606、99 秒）

| 時刻 | 出来事 |
|---|---|
| 約 8 秒 | 約 14 km で 2 機とも撃つ。相手も同時に撃つ（撃ち合い）。自軍の 1 発が命中し、相手 1 機を撃墜 |
| 14 秒・39 秒 | 残った相手の弾（約 14 km・約 10 km）を、2 発ともかわす |
| 78 秒 | 約 5 km まで詰めて撃ち返し、命中（敵全滅。自軍は無傷） |

### 同じ初期配置（100601）での、こちらのモデルの負けと先方モデルの勝ち

| 時刻 | こちらのモデル（負け） | 先方モデル v1.3（勝ち） |
|---|---|---|
| 約 9〜10 秒 | 約 14 km で 2 機とも撃つ。相手も同時に撃つ（撃ち合い） | 同じく約 14 km で撃ち合い |
| 初弾の結果 | 自軍の 1 発が命中、相手の 1 発も命中（A0100 が撃墜される） | 自軍の 1 発が命中、相手の弾はすべて外れる |
| その後 | 残った A0200 が 35 秒に約 0.6 km まで近づかれて撃墜される（自軍全滅） | 35 秒に約 4.4 km で撃たれた弾を回避し、62 秒に約 3.5 km で撃ち返して命中（敵全滅） |

## 補足

- ここにあるのは機体とミサイルの位置・姿勢などの時系列だけで、方策への入力（観測）・内部状態（RNN）・出力（行動）は入っていない。必要なら同じ試合で取り出せる。
- 記録の作り方: 評価スクリプト `scripts/eval/evaluate_mhi_team.py` の `--acmi` で、1 試合ごとに `episode.acmi` を書き出す（`--telemetry-csv` で位置・速度・姿勢の CSV も出せる）。
