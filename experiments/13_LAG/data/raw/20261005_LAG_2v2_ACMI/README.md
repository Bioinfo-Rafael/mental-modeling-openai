## ACMIの基本項目

ACMIには、時刻を示す`#秒`の行と、オブジェクトごとの状態を示す行があります。位置・姿勢・速度などを読むための主な項目を以下に示します。

| 項目 | 意味・単位 |
|---|---|
| `#秒` | シミュレーション開始からの経過時間（秒） |
| オブジェクトID | 記録対象を区別する識別子 |
| `T=経度\|緯度\|高度\|ロール\|ピッチ\|ヨー` | 位置と姿勢。経度・緯度は度、高度はm、姿勢角は度 |
| `Name` | 記録対象の名称 |
| `Color` | 表示色（`Red` / `Blue`） |
| `TAS` | 真対気速度（m/s） |
| `Health` | 記録対象の状態値 |
| `-ID` | 指定IDのオブジェクトを表示から削除する記録 |

この表は位置・姿勢などの読み取りに必要な項目の抜粋であり、ACMI内の全項目を列挙したものではありません。

## 閲覧方法

- ACMIはTacviewで開きます。
- 動画は`recordings/`内の同名のMP4を参照します。
- 行動CSVは`actions/`内を参照します。ACMIとCSVは別ファイルです。

## 収録範囲

ACMIはオブジェクトの位置・姿勢などの時系列を記録しています。方策への入力観測、RNN内部状態、選択した行動はACMIには含まれません。別途収録された行動・状態については、`actions/`のCSVとその列定義を参照してください。
