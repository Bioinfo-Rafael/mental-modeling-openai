# targets_v1

foresight_short_v1から、各機体の目的・行動に他者との関係を必須化する。
守る・支援する相手、回避する機体・ミサイル、攻撃対象、自機を狙う敵機・ミサイルを、根拠がある範囲でID付きで記述する。
相手や役割を推定できない場合は、特定できない関係を明記する。非活動機は活動的な役割がない旨を記述する。
全機体に全役割を割り当てる指示ではない。推定した関係には留保を付ける。
1機55英単語・1文から、80英単語以内・1〜2文へ変更する。
userテンプレート、入力窓、モデル、生成設定、反復数は維持する。
比較には関係性の指示追加と語数・文数上限の変更が含まれる。
誰から狙われているかも各回答で明記する。攻撃機・ミサイル・標的を区別し、特定不能ならその旨を述べる。近さだけから標的関係を断定しない。
