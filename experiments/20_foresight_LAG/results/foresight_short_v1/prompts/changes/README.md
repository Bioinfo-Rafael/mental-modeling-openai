# foresight_short_v1 の差分

起点は17の保存済み tactical_short_batch_v2。5窓の保存メッセージとsystem/userを照合した。

- 環境・状態・行動の定義、Data conventions、ミサイル情報を原文どおり維持。
- 前後30step・窓全体の回顧を、可変の観測末尾と固定の対象区間[T,T+30]に変更。
- タスク・時間解釈・推論・出力の節を予測専用に整理。目的と主な動きのみ、1機1文・55語以内・4機JSON。
- 過去/現在の要約と根拠の説明は出力しない。userは区間とデータだけ。
- 3条件は同一テンプレート。61時点条件は観測済みの参照回答で、予測性能や正解そのものとは扱わない。
- 注釈ラベル・n・注釈対象機体はモデルに渡さない。Tは予測対象区間の指定であり、変化点と説明しない。
- 最新のユーザー指示に従い、v2の2文まで可という例外は引き継がず1文とした。

system.diff / user.diffは元の保存済み本文からの全差分。実行前に本文ハッシュと差分を再検証する。
